# IP and provenance records

These files are engineering records for licensing, source provenance, dated
measurements, and claim review. They are not patent applications, legal
opinions, ownership assignments, or additional license grants.

- [Claim register](CLAIM-REGISTER.md) — evidence classes and limits for public
  technical statements.
- [Source provenance](SOURCE-PROVENANCE.md) — first-party, dependency, and
  migration records.
- [Source release manifest](SOURCE-RELEASE-MANIFEST.json) — machine-readable
  fail-closed distribution decision and required clearance evidence.
- [Invention disclosure](INVENTION-DISCLOSURE-AND-PRIOR-ART.md) — dated
  implementation observations retained for historical reference.
- [Defensive prior-art record](DEFENSIVE-PRIOR-ART-CLAIMS.md) — search-oriented
  technical descriptions without a legal conclusion.

The Apache License 2.0, `NOTICE`, and the current contributor records control
the release. These documents cannot broaden those instruments.
